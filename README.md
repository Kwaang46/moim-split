# 모임 정산

같이 쓴 돈을 기분 좋게 나누는 모바일 친화적인 정산앱입니다.

## 사용

친구 추가 → 지출 기록 → 정산 결과 확인. 각 지출은 1원 단위로 균등 분담하며 나머지는 참여자 순서대로 배분합니다. 대신 결제한 사람을 분담에서 제외할 수도 있습니다.

- 반응형 UI, 모바일 하단 메뉴
- 지출 수정·삭제·되돌리기
- 정산 안내 복사, CSV 내보내기
- JSON 백업·복원
- 계정이나 서버 없이 브라우저에 저장

## 데이터

입력한 이름과 지출은 현재 브라우저의 localStorage에 저장됩니다. 저장소나 서버에 전송되지 않으며, 다른 기기와 자동 동기화되지 않습니다. 브라우저 데이터를 삭제하기 전에는 JSON 백업을 저장하세요. 로컬 HTML과 배포 주소는 저장 공간이 다르므로 JSON 백업·불러오기로 데이터를 옮겨야 합니다.

정산 안내는 실제 송금을 실행하거나 입금 여부를 확인하지 않습니다.

## 실행 및 배포

빌드나 설치가 필요 없습니다. index.html을 브라우저에서 열거나 정적 서버로 제공합니다. GitHub Pages의 main 브랜치 루트 폴더를 배포 원본으로 사용합니다.

## 디자인

사용자가 제공한 [Pinterest 레퍼런스](https://www.pinterest.com/pin/1150106823621412359/)의 밝은 보라색과 다채로운 카드 분위기를 참고했습니다. 화면 구성과 SVG 캐릭터는 이 정산앱을 위해 별도로 제작했으며, 레퍼런스 이미지는 포함하지 않습니다.
